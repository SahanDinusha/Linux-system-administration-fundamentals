# Linux System Administration Fundamentals

## Project Overview

This project demonstrates practical Linux system
administration skills using Red Hat Enterprise Linux 10.2.

## Environment

- OS: Red Hat Enterprise Linux 10.2
- Kernel: 6.12.0
- Virtualization: Oracle VirtualBox
- Architecture: x86_64

## Topics Covered

- Linux Fundamentals
- User and Group Management
- File Permissions
- File Management
- Process Management
- System Information

## Objectives

- Understand Linux system architecture.
- Perform essential system administration tasks.
- Manage users, groups and permissions.
- Monitor system resources and processes.
- Develop practical Linux troubleshooting skills.

## Practical Documentation

Each module contains commands, explanations,
verification results and screenshots.
